# ✨ VynixVault — Aesthetic Image Gallery

VynixVault is a responsive and interactive image gallery built with
HTML, CSS, and JavaScript.

It allows users to explore images through organized albums, search
for images, open image previews, and save their favorite images.
User preferences are also preserved using browser storage.

## ✨ Features

- 📁 Album-based image organization
- 🖼️ Responsive image gallery
- 🔍 Image search functionality
- ❤️ Favorite images
- 💾 Persistent favorites using Local Storage
- 🔎 Interactive image preview
- 🏷️ Image categories and tags
- 📱 Responsive design for different screen sizes
- ✨ Smooth and modern UI interactions
- ⚡ Fast and lightweight frontend

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Netlify

## 🎨 Design

VynixVault uses a modern dark interface with pink and purple
accent colors to create an aesthetic visual experience.

The interface includes:

- Sidebar navigation
- Album cards
- Image cards
- Search interface
- Responsive layouts
- Interactive buttons and states
